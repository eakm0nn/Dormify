# DORMIFY — กติกาการทำงานของระบบ

บันทึกจากข้อความผู้ใช้วันที่ 13 พฤศจิกายน 2026 (Asia/Bangkok)
ใช้เป็นข้อกำหนดสำหรับออกแบบและพัฒนาต่อ การบันทึกเอกสารนี้ไม่ได้หมายความว่าฟีเจอร์ทั้งหมดทำงานแล้ว

## กติกา 14 ข้อ

> ยืนยันเพิ่มเติม 14 พฤศจิกายน 2026: ผู้ใช้ยืนยันใช้ค่าเริ่มต้น 72 ชั่วโมง/ประกัน 1 เดือน/ครบกำหนด 5 วัน โดย Admin ปรับได้ ค่าเช่าล่วงหน้า น้ำไฟย้อนหลัง และต้องมีบัญชี User ก่อนทำสัญญา ข้อความรอยืนยันในประวัติเดิมด้านล่างถูกแทนที่ด้วยการยืนยันนี้

1. เช่าห้องพักเป็นทั้งห้อง ไม่แยกเตียง โดยหนึ่งห้องมีผู้พักหลายคนได้ แต่มีผู้รับผิดชอบหลักหนึ่งคน
2. User เลือกห้องและยืนยันความต้องการเช่าผ่านเว็บไซต์ จากนั้น Admin ตรวจสอบและอนุมัติ
3. เมื่อ Admin อนุมัติ ให้ระบบกันห้องชั่วคราว โดยเสนอระยะเวลา 72 ชั่วโมง และกำหนดให้ปรับค่าได้
4. ผู้เช่าไปตกลงรายละเอียดและทำสัญญากับเจ้าของหอพักภายหลัง โดย Admin บันทึกสัญญาในระบบ
5. ค่าเช่าเป็นรายเดือน กำหนดแยกตามห้องและบันทึกอัตราตามสัญญา
6. เงินประกันเสนอให้เท่ากับค่าเช่า 1 เดือน โดยบันทึกแยกจากรายรับค่าเช่า และรองรับการคืนเงินประกันเมื่อสิ้นสุดสัญญา
7. ค่าน้ำและค่าไฟคิดตามเลขมิเตอร์ที่ Admin กรอก ระบบคำนวณหน่วยและค่าใช้จ่ายให้อัตโนมัติ
8. อัตราค่าน้ำและค่าไฟต้องกำหนดได้ตามอัตราที่ใช้จริงและข้อกำหนดทางกฎหมาย
9. ออกบิลรายเดือนตามวันเริ่มสัญญา เสนอให้ครบกำหนดชำระ 5 วันหลังออกบิล
10. หากวันที่ของรอบบิลไม่มีในบางเดือน ให้ใช้วันสุดท้ายของเดือนนั้น
11. รองรับการชำระเงินสดและโอนเงิน โดย Admin ตรวจสอบและยืนยัน
12. ไม่รองรับการแบ่งชำระ และไม่มีค่าปรับชำระล่าช้า
13. ห้ามออกบิลซ้ำในรอบเดียวกัน และต้องเก็บประวัติอัตราค่าใช้จ่ายของบิลเดิม
14. ต้องตรวจสอบสิทธิ์ Admin และ User ทุกขั้นตอน

## สถานะการนำไปใช้

ข้อ 3, 6 และ 9 ได้รับการยืนยันจากผู้ใช้วันที่ 14 พฤศจิกายน 2026 แล้ว ใช้ 72 ชั่วโมง/1 เดือน/5 วันเป็นค่าเริ่มต้นและให้ Admin ปรับได้ ต้องเก็บค่าที่ใช้ในรายการเดิมเป็น Snapshot

| ข้อ | แนวทางเสนอ | สถานะ |
|---|---|---|
| 3 | กันห้องหลังอนุมัติ เริ่มต้น 72 ชั่วโมง ปรับได้ | ยืนยันแล้ว |
| 6 | ประกันเริ่มต้น 1 เดือน แยกรายรับค่าเช่า คืนหลังจบสัญญา | ยืนยันแล้ว |
| 9 | รอบบิลตามวันเริ่มสัญญา ค่าเช่าล่วงหน้า น้ำไฟย้อนหลัง ครบกำหนดเริ่มต้น 5 วัน | ยืนยันแล้ว |

ค่าที่ Admin เปลี่ยนมีผลกับรายการใหม่ สัญญา/บิล/การกันห้องเดิมใช้ Snapshot เดิม ผู้รับผิดชอบหลักต้องมีบัญชี USER ก่อนทำสัญญา
ข้อ 8 ยังต้องตรวจอัตราและเงื่อนไขที่ใช้กับหอพักจริงก่อนกำหนดค่าใช้งาน

รายละเอียดแบบข้อมูลและ Workflow ที่เสนออยู่ใน [Business Rules Design](analysis/PHASE1_BUSINESS_RULES_DESIGN.md)
หากสถานะการยืนยันในเอกสารออกแบบเก่าขัดกับเอกสารนี้ ให้ยึดกติกาและสถานะในเอกสารนี้
