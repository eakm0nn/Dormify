## การตีความที่ยืนยันแล้ว

- หอเดียว เช่าทั้งห้อง รับผิดชอบหลักหนึ่งคน ต้องมีบัญชี USER ก่อนสัญญา มีเพียง ADMIN/USER ไม่เพิ่ม Staff จากคำเกริ่น
- การยืนยันผ่านเว็บคือคำขอ รอ Admin กันห้องและลงนามภายหลัง ไม่ใช่สัญญาดิจิทัลทันที
- TypeScript ระบุ Frontend; Backend ใช้ Node/Express JavaScript ได้ MySQL เป็นฐานหลัก Prisma เป็น ORM
- ประวัติเงิน/สัญญาต้องคง Snapshot ไม่แก้ย้อนหลังให้ตรงค่าปัจจุบัน
- ข่าว/แจ้งเตือนอยู่ในเว็บ ไม่สมมติให้ต้องมี Email/SMS/LINE ไม่มีข้อกำหนดรีวิวหรืออาหารในรายการ 25 ข้อ ผู้ใช้สั่งถอดออกแล้ว
