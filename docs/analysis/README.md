## ขอบเขตหลักฐาน

- PDF ที่คำขอระบุ `แบบเสนอโครงงานเอกอมร(1).pdf` ไม่พบ; พบ `docs/requirements/แบบเสนอโครงงานเอกอมร.pdf` เพียงไฟล์เดียว จึงวิเคราะห์ไฟล์นี้แบบมีเงื่อนไข ไม่ยืนยันว่าเป็นฉบับเดียวกับ `(1)`
- ถอดและอ่าน Text Blocks ครบ 5 หน้า: 307 / 265 / 197 / 191 / 204 รวม 1,164 Blocks ไม่มี Block ถูกข้าม
- Thai glyph บางตัวไม่มี ToUnicode และตารางช่วงงานหน้า 4 ยังไม่ได้ตรวจเป็นภาพ จึงไม่อ้างว่าตรวจภาพ/วรรณยุกต์ทุกตัวครบ
- ตรวจโค้ด Routes/Controllers/Middleware/Schema, หน้าและ Components, Package/Lockfiles, การตั้งค่าและชุดทดสอบเดิม
- SQLite ถูกเปิดด้วย `mode=ro` พบทั้ง 6 ตารางว่าง ไม่อ่านข้อมูลส่วนตัวหรือเปิดเผย Secret
- อ้างผลรัน Phase 0 ก่อนหน้าแยกจากงานนี้: API 9/9 และ Build ผ่าน ไม่ได้รันทดสอบที่สร้าง Fixture หรือฐานใหม่ในงานวิเคราะห์นี้
- ไม่ติดตั้งแพ็กเกจ ไม่รัน Seed/Reset/Migration ไม่แก้ Source/Environment/ฐานข้อมูล บันทึกเฉพาะ Markdown ใต้ `docs/analysis/`

## ผลตรวจที่ต้องระวัง

Public Register ปิด ADMIN แล้ว แต่ยังสมัคร OWNER ได้ ซึ่งขัดกับ DORMIFY สองบทบาท
JWT ใช้ Secret ที่ตรวจแล้ว แต่ Token ยังอยู่ใน localStorage และ Logout ไม่ยกเลิก Token ที่ออกไป
Transaction ปัจจุบันอัปเดต Booking/Room พร้อมกัน แต่ไม่ตรวจสิทธิ์ครอบครองห้องอย่างเป็นอะตอม จึงยังยืนยันหลาย Booking ให้ห้องเดียวกันได้
การมี Transaction จึงยังไม่เท่ากับป้องกันการเช่าซ้ำ

ผล Audit ที่มีเป็นหลักฐานจาก Phase 0: Root 0; Frontend 4; Backend รวม Dev 2
ไม่ได้ Audit ใหม่หรือรับรองว่าแพ็กเกจไม่มีช่องโหว่ในวันที่นำไปใช้
